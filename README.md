# SnapRoyale

Unity 6 (URP 2D) で開発する横視点 2D ゲーム。

- ドキュメント索引: [Docs/README.md](Docs/README.md)
- AI 向け開発ルール: [CLAUDE.md](CLAUDE.md)

## 開発体制

ユーザーがディレクターとして仕様を決め、実装は主に Claude（AI）が Unity CLI 経由で行う。

## 動作環境

| 項目 | バージョン |
|---|---|
| Unity Editor | 6000.4.1f1 |
| Render Pipeline | URP (2D Renderer) |
| Unity CLI | 1.0.0-beta 系 |

## セットアップ（新しい環境で clone した場合）

```bash
git lfs install
git clone https://github.com/spicycurrydummy-cloud/SnapRoyale.git
unity open SnapRoyale
```
