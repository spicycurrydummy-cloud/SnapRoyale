| 状態 | 意味 |

| 草案 | Claude が起票、ユーザー未確認 |
| 確認中 | 不明点の質疑中 |
| 承認済 | ユーザーが承認。実装可能 |
| 実装済 | 実装・検証完了 |
| 保留 | 一旦見送り |
